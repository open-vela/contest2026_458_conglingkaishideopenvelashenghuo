## 拍摄要求

- 背景：白底或深色纯色，避免杂物
- 打光：均匀柔光；AMOLED 自发光，注意**避开屏幕反光**（可关掉顶灯、用侧光）
- 屏幕：先在上位机点「连接」完成校时，让表盘显示真实时间（不要出现 `--:--`）
- 构图：横构图 3:2，长边 ≥ 3000px；板子占画面 60%~70%
- 格式：JPG，单张 ≤ 10MB

## 拍摄顺序建议（约 20 分钟）

1. 先通电、连上位机、校时，让屏幕进入**表盘页** → 拍 `01 / 02 / 03 / 04`
2. 用上位机下发 `REMIND 60 喝水`，等 1 分钟到点，屏幕弹卡时拍 `06`
3. 手指滑动切页时拍 `05`（可用连拍挑一张）
4. 把整个桌面（板子 + 开着上位机 GUI 的电脑屏）拍进 `07`
